# Chatbot Persona Prototype — Leona (2D) / ARIA (3D)

互動式研究原型：同一套客服對話劇本（訂單出錯與物流錯誤），以「頭像擬人化程度」作為操弄變項，比較 2D 扁平頭像與擬真 3D 頭像／表情在使用者感受上的差異。

## 內容

- `index.html` — 單一檔案的完整原型（HTML + CSS + JS，無需額外依賴），可直接雙擊開啟或部署到 GitHub Pages。

## 功能

- 上方切換鈕可在 **2D**（低擬人化頭像）與 **3D**（高擬人化頭像，含載入／錯誤表情變化）之間切換。
- 兩種條件共用同一套對話流程與選項（語意相近），僅頭像呈現方式與回覆口吻不同，方便做操弄檢核比較。
- 所有機器人回覆皆附上可點擊選項，對話不會中斷在無法繼續的畫面。

## 用 GitHub Pages 部署

1. 建立一個新的 GitHub repository，把這個資料夾內容 push 上去。
2. 到 repository 的 **Settings → Pages**，選擇 `main` branch 的根目錄作為來源。
3. 儲存後，GitHub 會提供一個 `https://<你的帳號>.github.io/<repo名稱>/` 的網址即可線上瀏覽。

## 本機預覽

直接用瀏覽器打開 `index.html` 即可，不需要伺服器或安裝任何套件。
