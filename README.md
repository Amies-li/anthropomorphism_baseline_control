# Chatbot Baseline Control Prototype（無人設對照組）

互動式研究原型：客服對話劇本（訂單出錯與物流錯誤）的基準狀態版本，完全移除擬人化線索，作為與 Leona (2D) / ARIA (3D) 兩個人設條件比較的對照組。

## 內容

- `index.html` — 單一檔案的完整原型（HTML + CSS + JS，無需額外依賴），可直接雙擊開啟或部署到 GitHub Pages。

## 特色（對照組設計）

- **無頭像**：訊息不使用任何頭像或圖示，僅以對齊方向與底色區分「系統」與使用者。
- **無命名**：介面只標示「客服系統」，訊息中沒有任何暱稱或自稱。
- **無擬人化載入動畫**：以功能性進度條（0%→100%）取代打字動畫或表情變化，跑完直接顯示完整文字。
- **中性語氣與色彩**：文字改寫為公務、系統化的措辭，配色採中性灰階，避免顏色或用詞帶出情感聯想。
- 對話流程與選項結構與 Leona/ARIA 版本相同（語意相近），僅呈現方式與語氣不同，方便做操弄檢核比較。

## 用 GitHub Pages 部署

1. 建立一個新的 GitHub repository，把這個資料夾內容 push 上去。
2. 到 repository 的 **Settings → Pages**，選擇 `main` branch 的根目錄作為來源。
3. 儲存後，GitHub 會提供一個 `https://<你的帳號>.github.io/<repo名稱>/` 的網址即可線上瀏覽。

## 本機預覽

直接用瀏覽器打開 `index.html` 即可，不需要伺服器或安裝任何套件。
